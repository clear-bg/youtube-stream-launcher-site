プライバシーポリシー

YouTube Stream Launcher（以下「本ツール」）は、開発者個人が自身の YouTube チャンネルで配信枠を作成するために使用するローカルツールです。

取得する情報

本ツールは YouTube API サービスを利用し、Google アカウントの認可を得て、配信枠の作成・更新および再生リストの取得を行います。

情報の保存と利用

認証トークンおよび再生リスト情報は、利用者自身のコンピュータ上にのみ保存されます。外部サーバーへの送信や第三者への提供は行いません。

アクセス権の取り消し

本ツールへのアクセス許可は、Google アカウントの権限設定からいつでも取り消せます。

関連ポリシー

本ツールは YouTube API サービスを使用しています。YouTube 利用規約およびGoogle プライバシーポリシーもあわせてご確認ください。
